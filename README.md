# Morning Brief

Your day on one page, every weekday morning: to-dos from Slack and Notion, your PRs, your calendar, one thing to push forward, and a painting. Generated by Claude Code on your Mac with your own Claude subscription. No API keys.

## Install in one prompt

You need a Mac, the Claude desktop app with Claude Code, Node 20+, and `gh` logged in.

Open Claude Code in the Claude desktop app and paste:

```
Set up Morning Brief for me: run `gh repo clone carbonfact/morning-brief ~/Documents/GitHub/morning-brief` (or pull if it exists), then read ~/Documents/GitHub/morning-brief/SETUP.md and follow it step by step.
```

Claude checks your machine, asks 3 questions, installs the local server, creates the daily task and tells you what to click. About 5 minutes.

## Manual install

1. `gh repo clone carbonfact/morning-brief ~/Documents/GitHub/morning-brief`
2. `~/Documents/GitHub/morning-brief/scripts/install.sh`
3. Edit `data/config.json` (name, email, browser, workdir).
4. In Claude Code Desktop, create a scheduled task `morning-brief`, weekdays 07:30, with the content of `TASK_PROMPT.md` as prompt.
5. Sidebar, Scheduled, **Run now**, click **Allow** for each connector once.

## How it works

- `PROMPT.md` is the editorial spec. A Claude Code Desktop scheduled task reads it every weekday and writes `data/briefs/YYYY-MM-DD.json`.
- `server.mjs` serves the page on http://localhost:4747, remembers checked to-dos, picks the image of the day and falls back to an iCal feed for the calendar.
- `public/index.html` is the page. Gear icon top right: language, image source.
- The yellow buttons open a new Claude Code session in the desktop app with the task pre-filled.

## Good to know

- The Claude app must be open in the morning. Otherwise the brief is generated when you open it.
- Checked to-dos are never proposed again.
- Image sources: The Met, Cleveland Museum of Art, NASA, Bing, Unsplash (needs a free key).
- Everything stays on your Mac. `data/` is not committed.
